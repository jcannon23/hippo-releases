# Hippo for macOS

Hippo captures meeting audio and creates transcripts and meeting notes on your Mac.

## Download

[Download the latest stable release](https://github.com/jcannon23/hippo-releases/releases/latest).

Requires an Apple silicon Mac running macOS 26 or later. Download the ZIP, quit any running copy of Hippo, unzip it, and move Hippo.app to Applications. Builds are Developer ID signed and Apple notarized.

## Updates

Choose **Hippo → Check for Updates…**, or use **Settings → Updates**. Update checks are enabled by default; installation requires your approval. Hippo blocks update installation during recording and while finishing a meeting.

Stable updates are the default. To test upcoming releases, enable **Receive beta updates** in Settings → Updates. Beta builds may contain unfinished changes. Turning beta updates off does not downgrade your installed version; you will receive a stable update when its build number catches up.

If you already use an older Hippo build without an updater, install this release manually once. Subsequent updates can be installed from Hippo.

This repository contains public downloads, release notes, and the update feed. Application source is maintained separately.
